# Artık Yıl Kontrolü

### Projenin Amacı Nedir?
Python'da fonksiyonlar ve koşullu ifadeler kullanarak bir yılın artık yıl olup olmadığını belirlemek.

### Program Ne İşe Yarar?
Girilen yılın artık yıl olup olmadığını kontrol eder. Artık yıl ise `True`, değilse `False` döndürür.

### Program Nasıl Çalışır?
1. `is_year_leap()` fonksiyonu yılı kontrol eder.
2. Yılın 4, 100 ve 400'e bölünebilme durumları değerlendirilir.
3. Sonuç `True` veya `False` olarak döndürülür.
4. Test sonuçları doğruysa ekrana `OK` yazdırılır.

### Kullanılan Python Yapıları Nelerdir?
- `def`, `return`
- `if`, `elif`, `else`
- `%` operatörü
- `for` döngüsü
- Listeler
- `True`, `False`

### Programın Beklenen Çıktısı Nedir?
```text
1900 -> OK
2000 -> OK
2016 -> OK
1987 -> OK
```

### Program Nasıl Çalıştırılır?
Python IDLE üzerinden `.py` dosyası açılır ve F5 tuşuna basılır.
